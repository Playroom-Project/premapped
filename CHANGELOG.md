# Changelog

## 0.1.0-alpha.1 — Worldgen Foundation

- Reorganized the supplied template into Architectury common/Fabric modules.
- Pinned Java 17, Minecraft/Yarn, loader/API and build dependencies.
- Refreshed the Gradle 8.10.2 wrapper with a pinned distribution checksum.
- Added bounded lazy plans and an async serial state machine.
- Added stored FULL checks, checksummed snapshots and atomic checkpoint commits.
- Added manual recovery, Pause/Cancel and explicit worldgen-change approval.
- Added vanilla menu entry points and playerless bootstrap interception code.
- Added English Javadoc/comments, architecture/specification/test documentation.
- Added English/Norwegian UI and Java 17 CI.

Real-game and full Playroom Project acceptance remain release gates. Preview,
adaptive gameplay controls and separate DH LOD jobs remain later milestones.
